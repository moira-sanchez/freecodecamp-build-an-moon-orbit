# 🌙 Órbita Lunar Animada

Este proyecto consiste en una animación creada con HTML y CSS que representa la órbita de la Luna alrededor de la Tierra.

La actividad permitió practicar el uso de posicionamiento, Flexbox y animaciones CSS mediante `@keyframes`. También personalicé el proyecto agregando una imagen del espacio como fondo.

## Tecnologías utilizadas

- HTML
- CSS

##  Conceptos utilizados

- Flexbox
- Posicionamiento relativo y absoluto
- `transform`
- `border-radius`
- `@keyframes`
- `animation`
- Media queries
